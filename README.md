# EXCEPTION-HANDLING--Banking-ATM-System
Exception handling manages errors during program execution without crashing the application\.


Banking ATM System\.

## What the program does

- Creates a `BankAccount` class\.
- Implements deposit, withdrawal, and balance checking\.
- Handles negative deposits\.
- Handles invalid withdrawal amounts\.
- Handles insufficient funds\.
- Uses a custom `InsufficientFundsError`\.
